# Who's That? One Piece

A daily One Piece character guessing game for friends. Guess the hidden character in 8 tries using seven clues: gender, height, Haki, Devil Fruit, bounty, affiliation and first arc.

- `index.html` is the whole site (pages: Home, Play, How to Play, Archive).
- `characters.csv` is the 100-character list the game data was built from.

Fan-made and non-commercial. One Piece belongs to Eiichiro Oda and Shueisha.
